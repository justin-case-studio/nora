What does Nora
actually do?

The short version
START HERE   +

You never know which files will matter later. A contract, a draft, a photo, a spreadsheet — most likely you'll never need to prove anything about them. But for the few you do, having a tamper-proof record of when the file existed, in exactly that form, can be the difference between a clean resolution and an expensive one.

Nora is a desktop application that creates those records. It monitors a folder you choose, fingerprints each file with a SHA-256 hash, and permanently registers that fingerprint on the Bitcoin SV blockchain. The proof is yours forever, independent of Nora or any third party.

How it works, step by step +
  1. Point Nora at your folders Choose the directories you want to watch — work files, contracts, drafts, whatever matters.
  2. Start a registration run Nora reads every file in the watched directories — top to bottom.
  3. New or modified? Each file is checked against Nora's local database. Unchanged files are skipped; only new or modified ones move forward.
  4. Fingerprint Nora computes a SHA-256 hash of the file — a unique digital fingerprint, generated entirely on your machine.
  5. Register & store Nora registers the fingerprint on the Bitcoin blockchain — permanent, anchored to the moment of registration — and saves it to the local database for future runs.
  6. Verify, anytime Open any registered file in Nora's Verify panel — even years later — to confirm it still matches its blockchain record.
