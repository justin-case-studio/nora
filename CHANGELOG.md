## [1.1.0] - 2026-04-14

### Added
- Initial public release of Nora
- Automatic folder watching with configurable recursion and file size limits
- SHA-256 file fingerprinting + Bitcoin SV blockchain registration via MintBlue API
- Local trial mode — no blockchain account required to try the app
- Dashboard with registration stats and daily activity chart
- Per-file verification against blockchain record
- SQLite database of registered files with search, pagination, and CSV export
- Settings panel: API key, project ID, automation level, quiet hours
- First-run onboarding flow
- Cross-platform desktop app: Linux AppImage, Windows EXE, macOS bundle
